# Consignes Agent - WP Agency Ops Toolkit

## Rôle

Ce repo est piloté par une conversation ChatGPT externe qui joue le rôle d’architecte et chef de projet.

Codex est l’exécutant technique.

## Règles de travail

- Ne prends pas d'initiative produit hors ticket.
- Ne change pas le périmètre sans validation.
- Ne duplique pas WPUR.
- WPUR = maintenance plugins détaillée.
- WP Agency Ops = cockpit global WordPress.
- Chaque tâche doit finir par un rapport structuré.
- Toujours lister les fichiers modifiés.
- Toujours indiquer les tests lancés.
- Toujours signaler les limites et incertitudes.
- Ne jamais prétendre qu’un test passe s’il n’a pas été lancé.
- Préférer des petites passes atomiques.
- Ne pas ajouter de grosses features sans demande.
- Ne pas réécrire massivement l’architecture sans instruction.
- Si une demande touche aux plugins WordPress détaillés, vérifier si cela appartient plutôt à WPUR.
- Si une fonctionnalité existe déjà dans WPUR, ne pas la réimplémenter ici : créer seulement une intégration ou un import.
